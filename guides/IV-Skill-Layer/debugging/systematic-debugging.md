# systematic-debugging

Skill: disciplined debugging that finds the root cause.

## When to use
Any bug, test failure, or unexpected behavior — before proposing a fix.

## Core idea
Reproduce. Isolate. Hypothesize. Test the hypothesis with a single change. Repeat until the failure mode is fully explained. Only then write the fix.

## Rigid
Don't shortcut by guessing at fixes. The skill exists because guessing wastes time.
